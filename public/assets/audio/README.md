# Audio assets

These are **silent placeholder files** so the video previews/renders without
errors. Replace them with real audio; if you change filenames, update the paths
in **`src/lib/audio.ts`**. Mix levels also live there.

```
music-bed.wav          ← cinematic-electronic bed, loops under the whole film (low mix)
sfx/whoosh.wav         ← transition swoosh (one per scene cut)
sfx/click.wav          ← cursor click on buttons
sfx/pop.wav            ← element lands into place
sfx/type.wav           ← typing / field entry
sfx/success.wav        ← success chime (logo land, purchase)
sfx/notify.wav         ← notification / OTP pop
sfx/swipe.wav          ← swipe / tab switch
vo/<sceneId>.wav       ← per-scene voice-over — generated by `npm run vo`
```

## Voice-over

Don't hand-make these — run the generator:

```bash
ELEVENLABS_API_KEY=sk_...  npm run vo
```

It fills `vo/logo.wav`, `vo/dashboard.wav`, `vo/fund.wav`, `vo/numbers.wav`
(and the later scenes) from the script in `src/content.ts`.

MP3, WAV, and M4A all work with Remotion's `<Audio>` if you'd rather drop in your
own files — just match the filenames or update `src/lib/audio.ts`.
