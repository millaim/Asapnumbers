# AsapNumbers — Onboarding & Product Showcase (Remotion)

A premium, Apple/Stripe/Linear-style product film for **AsapNumbers** — the real
interface (from the product screenshots) rebuilt as **live, animated UI** and
walked through step by step: dashboard, funding a wallet via a generated virtual
account, buying a virtual number, and receiving an OTP.

- **Format:** Vertical **1080×1920 @ 60fps** (a landscape 1920×1080 variant is planned — see below).
- **Motion:** spring-based "buttery" easing everywhere; camera push-ins, staggered
  reveals, a dynamic cursor with clicks, toasts, glow, and never-static frames.
- **Sound:** music bed + per-scene voice-over + frame-locked SFX (all wired to
  silent placeholders you swap for real audio).

> **Status — first pass (depth-first):** four flagship scenes are fully built and
> sequenced: **Logo Reveal → Dashboard → Fund Wallet → Virtual Numbers**. The
> remaining storyboard scenes (Homepage, Create Account, Login, Utilities,
> Purchase flow, Final montage) have their VO written and slot into the same
> system next.

## Preview & render

```bash
npm i
npm run dev         # Remotion Studio — sidebar has PromoVideo + each scene solo
npm run render      # → out/asapnumbers-vertical.mp4  (H.264, high quality, 60fps)
npm run render:hq   # → ProRes 4444 master (.mov)
```

## Voice-over (ElevenLabs)

The full narration script lives in `src/content.ts` (`SCRIPT[].vo`). Generate the
audio with one command:

```bash
ELEVENLABS_API_KEY=sk_...  npm run vo      # optional: ELEVENLABS_VOICE_ID=...
```

This writes `public/assets/audio/vo/<sceneId>.wav` — the exact paths the video
already references, so VO drops in with no further wiring. (Sandbox note: this
must run where `api.elevenlabs.io` is reachable.)

## Sound design & music

`src/lib/audio.ts` is the single config for **music**, **SFX**, and **VO**, with a
per-cue mix. All point at silent placeholders in `public/assets/audio/` right now
— replace them with your real files (keep the names, or update the paths):

| Layer  | File(s)                                   | Notes                              |
| ------ | ----------------------------------------- | ---------------------------------- |
| Music  | `music-bed.wav`                           | cinematic-electronic loop, low mix |
| SFX    | `sfx/{whoosh,click,pop,type,success,notify,swipe}.wav` | frame-locked one-shots  |
| VO     | `vo/<sceneId>.wav`                        | generated by `npm run vo`          |

The **SFX timeline** is data-driven: whooshes land on every transition
(`lib/timeline.ts`), and per-element `<Sfx>` cues fire at exact landing frames
inside each scene (see the bottoms of the scene files).

## Landscape (1920×1080) variant — planned

The scenes are token-driven, so the landscape cut reuses every component; only
layout constants change (side-by-side columns instead of stacked). It'll be added
as a second set of compositions in `Root.tsx` at 1920×1080.

## Headless-render note

`@remotion/google-fonts` fetches Sora/Inter from Google's CDN at render time —
fine locally. On a locked-down CI box, allowlist `fonts.gstatic.com` or switch
`src/lib/fonts.ts` to bundled local fonts.
